# FOOTBALL — interactive UX prototype

Static, self-contained React prototype for amateur football.
Poster design, Russian / English / Hebrew and RTL.

All teams, players, payments, messages and sign-in flows are demonstrations.
Changes stay in each visitor's browser. No real payments or external messages.

## GitHub Pages

Publish this `gh-pages` branch from `/ (root)` in Settings → Pages.
Expected site URL after deployment: https://satorimen.github.io/FOOTBALL/

Third-party font and runtime licenses are in `licenses/`.
